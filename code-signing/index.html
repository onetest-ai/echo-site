Code signing policy

Applies to the Windows releases of Echo.

Free code signing provided by SignPath.io, certificate by SignPath Foundation

What is signed

The Windows binaries of Echo, the echoctl.exe program and its MSI installer, are built from the public source repository github.com/onetest-ai/echo by GitHub Actions, using the workflow .github/workflows/windows-release.yml. They are then signed through SignPath. Signing happens only for builds from that workflow, never for binaries built on someone's own computer.

Every release must be approved by hand before it is signed. Only official Echo releases are signed.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. The services Echo can connect to, all set up by the user, are described in the privacy policy.

Installing and uninstalling

On Windows, Echo installs with its MSI installer. To uninstall, open Settings → Apps → Installed apps, find Echo and choose Uninstall. Uninstalling leaves your data folder (transcripts, minutes, notes) in place. Delete that folder yourself if you no longer want it.
