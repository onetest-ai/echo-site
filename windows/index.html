Windows builds

How the Windows releases of Echo are made, and why Windows warns about them for now.

Echo's Windows installer isn't code-signed yet. Windows SmartScreen may say "Windows protected your PC" and name an unknown publisher. Choose More info → Run anyway to install. We will sign the builds once we have a certificate.

Where the builds come from

The MSI installer and the zip are built from the public source repository github.com/onetest-ai/echo by GitHub Actions, with the workflow .github/workflows/windows-release.yml, when a release is published. Nothing is built on someone's own computer, and nothing is cached between releases.

How updates are checked

  • Echo updates itself only from its GitHub releases.
  • Before it installs an update, it checks the installer's SHA-256 against the digest GitHub publishes for that release. A file that doesn't match is not installed.
  • The macOS app is signed with an Apple Developer ID and notarized by Apple.

Installing and uninstalling

The MSI installs Echo for your user only — no administrator rights — in %LOCALAPPDATA%\Programs\echo. To uninstall, open Settings → Apps → Installed apps, find Echo and choose Uninstall. Your data folder (transcripts, minutes, notes) stays; delete it yourself if you no longer want it.

Echo sends nothing to other systems unless you set it up: see the privacy policy.
