Install Echo

About 15 minutes, most of it downloads. Each step ends with a check, so you know it worked before you go on.

You need a Mac with macOS 14.2 or later (Apple Silicon), or a PC with Windows 10 version 2004 or later; the new Microsoft Teams app; and, for minutes, a Claude account (Pro, Max, Team or Enterprise) with Claude Code. Echo records and transcribes without Claude Code; Claude Code writes the minutes, action items and each thread's work.

1. Install Echo

macOS

  1. Download Echo-<version>-macos-arm64.dmg from the latest release.
  2. Open it and drag Echo onto Applications.
  3. Open Echo from Applications. Its octopus appears in the menu bar and in the Dock.

Windows

  1. Download echo-<version>-windows-x64.msi from the latest release.
  2. Run it. Windows may say it protected your PC: the installer isn't code-signed yet (why), so choose More info → Run anyway. No administrator rights are needed.
  3. Echo starts when the installer ends. Its octopus is in the tray, behind the ^ next to the clock.

Check: the octopus is there. If the macOS menu bar is full it hides icons — click Echo in the Dock to open its window.

2. First start

Echo asks for three things the first time:

  1. Where to keep your calls. Pick a folder, for example ~/Echo (Documents\Echo on Windows). Everything Echo makes stays there.
  2. A speech model. Accept the suggested one. It downloads once (0.5–1.5 GB); after that speech becomes text on your computer, offline.
  3. Permissions (macOS). Allow Microphone (your voice) and System Audio Recording (the others in the call, from Teams only). Accessibility is optional: with it Echo follows your mute in Teams and knows who is speaking.

Check: menu → Open Echo… → Settings → Health. Each permission has a ✓. If one doesn't, click Ask for permissions, or Open settings beside it.

3. Install Claude Code

Skip this if claude --version already works in a terminal.

  1. Install it. On macOS, open Terminal and paste: 
    curl -fsSL https://claude.ai/install.sh | bash
    On Windows, open PowerShell and paste: 
    irm https://claude.ai/install.ps1 | iex
    Other ways (Homebrew, npm) are on Claude Code's setup page.
  2. Open a new terminal window (the old one doesn't see the new command) and run claude. Sign in with your Claude account when it asks, then type /exit.

Check: in Echo, Settings → Health → Claude Code shows three rows.

4. Connect Claude Code to Echo

Settings → General → Claude Code plugin → Connect (or the menu: Claude Code → Connect Claude Code). It installs Echo's plugin into Claude Code for Echo's data folder — the status line, /echo:process-call, /echo:record and /echo:doctor — and then checks that Claude Code really lists it. If it doesn't, the notification says so and what to run instead.

For every Claude Code session on this computer, not only Echo's: echoctl claude connect --scope user.

Check: Settings → Health → Echo plugin has a ✓, and Settings → General → Claude Code plugin says Installed ✓.

5. Microsoft 365: calendar, chat, mail

Settings → Calendar & chat → Account → Sign in… Your browser opens your organisation's sign-in. Echo reads your calendar and meeting chats, and sends the mail you ask Claude to send, with its own sign-in.

Echo uses CodeMie's public app registration. If your IT blocks it, ask them to approve it, or to register an app for you and put its ID under App registration → Change… on the same page.

Mail from Claude in the Echo window always goes through Echo first, from your own account and after you say yes. Claude uses its own Microsoft 365 connector only when Echo can't send; if neither can, it opens a draft in your mail app.

Check: the Calendar view shows today's meetings.

6. Try it

  1. Menu → Record next call, then join a Teams call — a test call with a colleague is fine. The octopus turns green, then orange while it records.
  2. Hang up. A notification says the transcript is ready and when the minutes come: 15 minutes later, or click Write minutes on the call's Minutes tab.
  3. Open the call: Minutes, Transcript, Actions.

If the minutes fail, the Minutes tab says why, and Show log shows what Claude Code did.

Optional

  • Command line: Settings → General → Command line → Install… puts echoctl in your terminal (macOS asks for your password).
  • Start at login: Settings → General (on by default).
  • Brain: Settings → Brain → Use the Brain (off by default) indexes your calls and your threads' mail, channels and folders for search and for Claude.

Updating and removing

Echo checks for updates every 6 hours and offers them in its menu (Update to …). Removing Echo keeps your calls: on macOS drag Echo from Applications to the Bin; on Windows open Settings → Apps → Installed apps → Echo → Uninstall. Your calls folder stays where you put it.
