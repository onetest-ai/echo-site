1. Install Echo

  1. 1

    macOS

    Download the dmg, open it and drag Echo onto Applications. Open Echo from Applications: its octopus appears in the menu bar and in the Dock.

  2. 2

    Windows

    Download the installer and run it. Windows may say it protected your PC: the installer isn't code-signed yet (why), so choose More info → Run anyway. No administrator rights are needed; Echo starts when it ends, in the tray behind the ^ next to the clock.

Check: the octopus is there. A full macOS menu bar hides icons — click Echo in the Dock to open its window.

2. First start

Echo asks for three things the first time.

Where to keep your callsa folder

For example ~/Echo, or Documents\Echo on Windows. Everything Echo makes stays there.

A speech model0.5–1.5 GB, once

Accept the suggested one. After the download, speech becomes text on your computer, offline.

PermissionsmacOS

Allow Microphone (your voice) and System Audio Recording (the others in the call, from Teams only). Accessibility is optional: with it Echo follows your mute in Teams and knows who is speaking.

Check: menu → Open Echo… → Settings → Health. Each permission has a ✓; if one doesn't, click Ask for permissions, or Open settings beside it.

3. Install Claude Code

Skip this if claude --version already works in a terminal.

  1. 1

    Install it

    Paste one line into Terminal on macOS or PowerShell on Windows. Other ways (Homebrew, npm) are on Claude Code's setup page.

  2. 2

    Sign in

    Open a new terminal window — the old one doesn't see the new command — and run claude. Sign in with your Claude account when it asks, then type /exit.

Check: in Echo, Settings → Health → Claude Code shows three rows. Check again after fixing one; echoctl claude prints the same from a terminal.

Claude Code✓ found, and it starts

Not installed: do this step again. Doesn't start: reinstall it (an npm install also needs Node.js).

In a terminal✓ a new terminal finds claude

Click Add to PATH (or run echoctl claude path), then open a new terminal. Echo itself finds Claude Code without it.

Echo plugin✓ Claude Code lists it

4. Connect Claude Code to Echo

Settings → General → Claude Code plugin → Connect, or the menu's Claude Code → Connect Claude Code. It installs Echo's plugin into Claude Code for Echo's data folder — the status line, /echo:process-call, /echo:record and /echo:doctor — and then checks Claude Code really lists it. If it doesn't, the notification says so and what to run instead.

For every Claude Code session on this computer, not only Echo's:

echoctl claude connect --scope user

Check: Settings → Health → Echo plugin has a ✓, and Settings → General → Claude Code plugin says Installed ✓.

5. Microsoft 365: calendar, chat, mail

Settings → Calendar & chat → Account → Sign in… Your browser opens your organisation's sign-in. Echo reads your calendar and meeting chats, and sends the mail you ask Claude to send, with its own sign-in.

Echo signs in with the public app registration of CodeMie Code, the open-source Claude Code wrapper — the same one its Microsoft 365 skill uses, so your IT may have approved it already. If your IT blocks it, ask them to approve it, or to register an app for you and put its ID under App registration → Change… on the same page.

Mail from Claude in the Echo window always goes through Echo first, from your own account and after you say yes. Claude uses its own Microsoft 365 connector only when Echo can't send; if neither can, it opens a draft in your mail app.

Check: the Calendar view shows today's meetings.

6. Try it

  1. 1

    Record

    Menu → Record next call, then join a Teams call — a test call with a colleague is fine. The octopus turns green, then orange while it records.

  2. 2

    Hang up

    A notification says the transcript is ready and when the minutes come: 15 minutes later, or click Write minutes on the call's Minutes tab.

  3. 3

    Read it

    Open the call: Minutes, Transcript, Actions. If the minutes fail, the Minutes tab says why, and Show log shows what Claude Code did.

Optional

Command line

Settings → General → Command line → Install… puts echoctl in your terminal (macOS asks for your password).

Start at login

Settings → General. On by default.

The Brain

Settings → Brain → Use the Brain, off by default: your calls and your threads' mail, channels and folders, searchable for you and for Claude.

Plugins

Settings → Plugins: Scheduler, Telegram, Obsidian and your own — write one.

When something fails

No octopus in the menu bar

Click Echo in the Dock, or open it from Applications. A full menu bar hides icons.

A recording is silent

Settings → Health: Microphone and System Audio Recording need a ✓. Run /echo:doctor in Claude Code.

"Claude Code is not installed"

Step 3, then Check again in Settings → Health.

claude: command not found

Settings → Health → Add to PATH (or echoctl claude path), then open a new terminal.

Minutes say "Not logged in"

Run claude in a terminal and sign in again, or click Sign in… where the call shows the error.

"An older Echo plugin"Settings → Health

Click Update it, then restart Claude Code.

Claude doesn't know about a callClaude in the Echo window

The call was recorded on another AI profile: pick that profile in the Claude panel.

Updating and removing

Echo checks for updates every 6 hours and offers them in its menu (Update to …). Removing Echo keeps your calls: on macOS drag Echo from Applications to the Bin; on Windows open Settings → Apps → Installed apps → Echo → Uninstall. Your calls folder stays where you put it.
